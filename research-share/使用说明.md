# Agent 技术研究 · 导航与使用

阅读入口：`dist/index.html`。它是两份研究的导航页。分享时请保留 `dist` 内的 `index.html`、`agent-research.html`、`dsh-meeting.html` 和阅读说明，再让读者用浏览器打开入口。两份研究网页各自内嵌正文、样式、图标和交互，Agent 研究页还包含两份完整原文；阅读不依赖外部资源，查看官方参考链接时需要联网。

## 使用

- 顶部“逐页模式”：按主题讲解；左右方向键切换，Esc 退出。长主题可以继续上下滚动。
- “术语索引”：搜索中文、英文或缩写。
- 左侧目录或手机顶部目录按钮：定位到任意主题。
- 第一部分 Q1：点选五个分类维度，组合产品画像；可展开服务范围与专业领域的二维坐标图。
- Q2：点击八类技术职责，查看解释、案例与边界，关联连线同步高亮。
- Q3：对照模型应用、工作流、智能体的执行路径；“推进一步”展示六步库存调查示意，“重置”返回第一步。
- Q4：切换能力扩展、任务运行、上下文数据三组关系图；标签支持左右方向键。
- 第二部分 Q5：切换生态全景、五条构建与执行路线、项目归属表；点击八类节点看边界；31 个比较对象支持搜索与来源筛选。
- Q6：切换委派、并行、顺序、移交、审查五种协作图；说明控制权、执行次序和反馈关系。
- Q7：点击六种运行问题，查看需要的保障职责、任务状态与处理边界；可展开四类实现路线。
- 第三部分 Q8：切换五个业务示例，或调整四项判断条件，查看系统形态与平台化判断。
- Q9：切换六组能力示例，或点击可选能力，自定义行业智能体需要的能力组合。
- Q10：切换五个需求场景，联动实现分工、选择理由与加测任务；展开六类候选路线查看项目与核验条件。
- 第四部分 4.0：用共同底座图说明入口、DSH、问数插件与 Java 业务服务的分工和推荐条件。
- 4.1：切换正常、时点不明、实际增加、无数据、权限不足、超时六种查询场景，查看处理位置与正确回应。
- 4.2：切换数量核平、尚有差额、追问原因三种分析场景；瀑布图与差额公式同步更新，区分变动构成和业务原因。
- 4.3：切换粮食、零售、制造行业资产；在第二个标签查看配置校验、审批、版本绑定与运行分工。
- 4.4：点击查询型、分析型、可配置型，查看增量交付、同任务验收与重新评估条件。
- 最后一节“打印正文 / 导出 PDF”：打印正文，包含概念与协作模式各分组，完整原文附录不重复打印。未生成或验收 PDF 文件。
- “章节链接”：本机文件和本地预览会提示发送 HTML；部署后的网页可复制章节链接。

## 继续编辑

- `portal.html`、`portal.css`：两份研究的统一入口。
- `navigation.mjs`、`navigation.css`、`navigation.js`：两份研究共用的切换菜单。
- `content.html`：导览、结论与资料，以及各模块占位。
- `foundation.html`、`foundation.css`、`foundation.js`：第一部分四组图与交互。
- `ecology.html`、`ecology.css`、`ecology.js`：第二部分三组图、项目清单与交互。
- `selection.html`、`selection.css`、`selection.js`：第三部分形态判断、能力组合、实现分工与验证方案。
- `practice.html`、`practice.css`、`practice.js`：第四部分共同底座、查询场景、分析证据、行业配置与交付验证。
- `style.css`：全站视觉、响应布局与打印样式。
- `app.js`：全站导航、逐页模式与既有交互。
- `build.mjs`：生成导航页、Agent 研究页，并调用 `meeting/build.mjs` 生成 DSH 研究页；三份网页分别自包含。

维护前安装脚本运行环境（Node.js 20 或更新版本），在仓库根目录执行 `npm ci` 安装文档渲染库（marked），再执行 `npm run build` 生成三份交付网页。也可在安装依赖后进入 `research-share` 执行 `node build.mjs`。依赖版本由根目录锁定文件固定；构建需要根目录的两份原始文档。阅读最终网页无需安装依赖。

在仓库根目录可用 `python -m http.server 18765 --bind 127.0.0.1 --directory research-share/dist` 启动本地预览。此预览地址只能在本机访问。
