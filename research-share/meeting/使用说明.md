# DeepSeek Harness 设计理念与架构解析

交付文件：`../dist/dsh-meeting.html`。浏览器直接打开，或发送这一个文件给同事。正文、样式、图标、分类数据和交互全部内嵌，阅读不需要 Node.js、Python 或其他依赖。查看官方资料链接需要联网。

默认逐页演示，共 8 页：设计出发点、时空可组合、整个系统组件化、三个架构特点、生态分类与协作、构建与执行的五种路线、DSH/OpenCode/Pi 同类比较、行业选型判断。

- 逐页模式中，左右方向键、PageUp/PageDown 或底部按钮按全篇顺序翻页；Home/End 到首页/末页。阅读模式保留浏览器滚动键。
- 鼠标滚轮向下进入下一页，向上返回上一页；长页和内部滚动区域先正常滚动，到边缘后稍停再滚即可翻页。同一段滚动不会连续跳页；阅读模式、输入框、弹窗及横向表格保留原有滚动。
- 顶部“切换研究”可进入 Agent 架构研究或返回统一导航；离线切换需将三份 HTML 放在同一目录。
- 顶部三个章节标明共 2、2、4 页；下方列出当前章节每页的标题和章内页码。点击章节进入该章第一页，点击子页标题进入指定页；子页导航的左右键和 Home/End 在本章内移动。
- 底部显示全篇页码及下一页标题；跨章时标明“下一章”。第三部分按生态地图、构建路线、同类框架对比与行业选型展开。
- 第二页切换插件/服务状态，展示清理与依赖机制；它只是示意。
- 第三页点击组件查看职责。
- 第五页点击八个生态类别，查看小类、代表项目和职责边界；相邻协作连线同步高亮。
- 从第五页的“展开五种路线”进入第六页，再点击“比较 DSH / OpenCode / Pi”进入第七页；也可按顺序翻页。
- “项目归属表”列出 31 个具体项目或比较对象，标注原始研究、研究补充、生态示例，以及原仓库分组的对应关系。
- 阅读模式展开全部页面；资料依据和项目归属表以弹窗打开，Esc 关闭。弹窗打开时方向键不触发翻页。
- 浏览器打印会展开全部页面。未生成或验收 PDF 文件。

分类按具体交付物的主要技术职责定位。同一项目的产品与可复用执行部分分别记录，例如 OpenCode/Pi 的成品助手属于第⑧类，执行与嵌入部分在第②类比较。五种路线描述设计重心，功能可以重叠。图中箭头表示职责间可组合的关系，不代表所列项目已完成集成，也不是固定执行顺序。

统一入口为 `../dist/index.html`，另一份研究为 `../dist/agent-research.html`。两份研究各自独立；仓库原始 Markdown 保持不变。
