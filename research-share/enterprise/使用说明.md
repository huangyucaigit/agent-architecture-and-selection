# 企业 Agent 集成架构与 MCP 能力接入体系

交付文件：../dist/enterprise-agent.html。直接用浏览器打开；正文、原文、图示、样式和交互全部内嵌，阅读不需要安装依赖。查看官方参考资料需要联网。

## 内容与操作

- 总体架构：设计目标、可点击的目标架构图，共 2 页。
- 身份与能力：职责边界、三种身份调用示意、知识库／问数／业务三类能力，共 3 页。
- 决策与演进：三种接入方式的取舍、三阶段演进、已定决策与落地未定项，共 3 页。
- 顶部章节进入该章首页，下方具名页面导航可直接选择子页；底部显示下一页或下一章标题。
- 左右方向键与滚轮可逐页切换。长页先正常滚动，到边缘后稍停并再次滚动即可翻页。
- 身份、能力、演进选项支持点击、左右键与 Home/End，操作选项时不会触发全篇翻页。
- 阅读模式展开全部八页；设计原文在弹窗中完整保留。研究菜单可进入另两份研究或统一导航。
- 打印图示会打印八个主题，各交互面板保留当前选择，不自动打印所有选项或原文；原文可在资料弹窗查阅。未生成或验收独立 PDF。

## 维护与来源

源文件为 content.html、style.css、app.js；build.mjs 读取根目录《企业Agent集成架构与MCP能力接入体系设计决策备忘录.md》并内嵌完整原文。原始文档保持不变。
在仓库根目录执行 npm run build，一次生成统一入口和三份研究，共四份 HTML；npm run check 检查结构与链接。单独更新本专题也可执行 node research-share/enterprise/build.mjs。
图解整理与补充资料核对：2026-10-29。身份可信绑定、目标资源凭据与最终业务检查的安全限定有单独标注，并保留 MCP 官方规范和 DSH 安全资料入口。
本文呈现架构设计，不连接企业身份、模型或业务服务，交互结果是本地示意。网关产品、凭据方案、部署方式和具体实施契约仍待确定。
